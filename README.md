# 🔥 30-Дневный Челлендж (Серёжа & Лера)

Современное веб-приложение и **Telegram Mini App** для совместного прохождения 30-дневного челленджа с привычками, строгими правилами питания, синхронизацией в реальном времени и Telegram-ботом.

---

## 🎯 Правила челленджа

1. **Длительность**: 30 дней непрерывного прогресса.
2. **Ежедневные активные привычки**:
   - 👟 **Минимальное количество шагов**: 6000 шагов
   - 🌙 **Время ко сну**: Лера — **23:30**, Серёжа — **00:00**
   - 🏋️ **Занятие спортом**: 40 мин
   - 🇬🇧 **Изучение английского**: 15 мин
3. **Постоянные правила (Правильное питание и лайфстайл)**:
   - 🚫 Без газировок
   - 🚫 Без сладкого
   - 🚫 Без снеков
   - 🚫 Без Сока
   - 🚫 Без майонеза и кетчупа
   - 🚫 Фастфуд (запрещено)
   - 🚫 Без жарки в масле
   - 🚫 Без алкоголя
   - 🚫 Без сигарет
4. **Условие сброса (Срыв)**:
   - Если происходит срыв по любому из правил питания или привычек, нажимается кнопка **«Зафиксировать срыв»** — стрик нарушителя немедленно сбрасывается на **День 1**, а партнёр получает уведомление в Telegram.
5. **Дедлайн и Grace Period (Льготный период)**:
   - Закрытие дня происходит с льготным периодом **до 12:00 следующего дня** (удобно, чтобы отметить вчерашний сон и вечерние шаги после пробуждения утром).

## 🚀 Быстрый запуск

### 1. Установка зависимостей (уже установлены)
```bash
npm run install:all
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
- **Клиент (UI)**: [http://localhost:5173](http://localhost:5173)
- **Сервер & API**: [http://localhost:3001](http://localhost:3001)
- **Telegram-бот**: Запускается автоматически с вашим токеном `@chall30_bot`!

### 3. Сборка и запуск в Production
```bash
npm run build
npm start
```
Сервер будет раздавать и интерфейс, и API, и Telegram-бота на порту `3001`.

---

## 📱 Запуск в Telegram Mini App

1. Бот уже настроен с вашим токеном в `.env`.
2. Чтобы открыть приложение внутри Telegram со смартфона:
   - При локальной разработке запустите туннель (например, `npx localtunnel --port 5173` или `ngrok http 5173`).
   - Укажите полученный HTTPS-адрес в `.env` в поле `WEBAPP_URL=https://ваш-адрес.loca.lt` и в настройках бота через **@BotFather** -> `/mybots` -> ваш бот -> **Bot Settings** -> **Menu Button** -> настроить Web App URL.
   - Откройте бота в Telegram и отправьте команду `/start` или нажмите кнопку меню **«🎯 Открыть челлендж»**.

## ✨ Возможности приложения

- 👦 👧 **Единый список задач**: на каждой задаче отображаются два интерактивных чекбокса/аватара (Серёжа и Лера), позволяя мгновенно видеть статус друг друга.
- ⚡ **Живая синхронизация (Real-time SSE)**: при отметке задачи на одном устройстве статус обновляется на втором без перезагрузки страницы.
- 🏆 **Шкала 30 дней и вехи**: визуальный прогресс (Старт 🚀, 7 дней 🔥, 14 дней ⚡, 21 день 🎯, Финал 👑).
- ⚙️ **Управление целями (CRUD)**: возможность добавлять новые привычки, задавать индивидуальные параметры (например, разное время сна) и редактировать правила питания.
- 📅 **История по дням**: календарный архив всех прошедших дней и срывов.
- 🤖 **Telegram-уведомления**: оповещения партнеру при закрытии всех задач дня или фиксации срыва, а также вечерние напоминания.
- 🎉 **Праздничные эффекты**: салют из конфетти и тактильный отклик (Haptic Feedback) при выполнении всех целей.
